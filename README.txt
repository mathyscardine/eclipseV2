🌑 ECLIPSE MOD - VERSION CORRIGEE

=== IMPORTANT ===
Si COMPILE.bat ne marche pas, utilise IntelliJ IDEA :
1. Ouvre le dossier avec IntelliJ
2. Attends que Gradle se configure (barre en bas)
3. Va dans l'onglet Gradle (droite) -> Tasks -> build -> double-clique

=== COMMANDES EN JEU ===
/eclipse start          → Force l'eclipse
/eclipse stop           → Arrete l'eclipse
/eclipse chance 10      → Met 10% de chance
/eclipse toggle         → Active/Desactive
/eclipse status         → Voir le statut

=== CONFIG ===
Le fichier config est dans :
%%appdata%%\.minecraft\config\eclipse-mod.json
